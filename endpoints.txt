LEGEND
  [DIRECT]   = CORS-enabled, call with directFetch() or plain fetch
  [PROXY]    = CORS-blocked origin, must go through PROXIES list via raceFetch()
  [WAF+UA]   = Also requires browser User-Agent spoofing (handled in self-hosted
               Cloudflare Worker at worker/cors-proxy.js)
  [STATIC]   = Static JSON generated by scripts/crawl/* under src/data/; read via
               `import … from "../../data/…"`
  TTL        = In-memory fetcher.js cache lifetime (default 5 minutes)

1. CORS PROXIES  (src/lib/constants.js → PROXIES[])
================================================================================
Race-based fallback chain. raceFetch() fires the direct URL + each proxy in
parallel via Promise.any() and keeps the winner.

  P1 (preferred, self-hosted):
     https://egx-cors-proxy.shokr.workers.dev/?url=<ENCODED_URL>
     - Deploy:  pnpm deploy:proxy  (config: worker/wrangler.jsonc)
     - Allow-list lives in worker/cors-proxy.js → ALLOWED_ORIGINS
     - Also injects a middleware-required header for beta.egx.com.eg
  P2:
     https://api.codetabs.com/v1/proxy/?quest=<ENCODED_URL>
  P3:
     https://api.allorigins.win/raw?url=<ENCODED_URL>

How to call (JS):
  import { raceFetch, directFetch } from "src/lib/fetcher";
  const data = await raceFetch(url, { validate: (d) => !!d?.data, cacheTTL });

  - Spoofs a desktop Chrome User-Agent
  - Injects the extra header EGX middleware requires
  - Retries with exponential backoff

12. ADDING A NEW EXTERNAL API — CHECKLIST
================================================================================
1. Add the URL to API in src/lib/constants.js.
2. If the origin lacks CORS → add it to worker/cors-proxy.js → ALLOWED_ORIGINS
   and redeploy with `pnpm deploy:proxy`.
3. Call via raceFetch() (proxied) or directFetch() (CORS-enabled). Always
   pass a `validate` predicate so the proxy race doesn't accept error
   envelopes.
4. If the endpoint feeds a crawler, add a script under scripts/crawl/ and
   wire it into scripts/crawl/all.js + package.json scripts.
